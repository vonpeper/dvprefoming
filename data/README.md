# Módulo de Datos Dinámicos (`data`)

Este directorio contiene las definiciones de datos simulados (mockups) para el desarrollo de la interfaz en fases iniciales.

## Responsabilidades
- Contener archivos JSON o TS de datos provisorios (`data/mock.ts`).
- Todos los datos expuestos son neutrales y actúan como marcadores de posición (`DRAFT`, `PLACEHOLDER`, `PENDING_CLIENT_INPUT`).
