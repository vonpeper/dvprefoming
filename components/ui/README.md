# Componentes UI de Presentación (`components/ui`)

Este directorio contiene componentes básicos, atómicos y altamente reutilizables. Deben ser puros, visualmente personalizables y libres de lógica de negocio.

## Responsabilidades Futuras
- Botones, inputs, modales, selectores y formularios básicos.
- Componentes estilizados que sirvan de bloques de construcción para la interfaz visual.
