# Biblioteca de Utilidades Comunes (`lib`)

Este directorio contiene funciones de ayuda y clientes compartidos que no corresponden a un módulo o feature de negocio específico.

## Responsabilidades
- Configuración de clientes (ej. cliente de Prisma u ORM futuro en `lib/db.ts`).
- Funciones de formateo (fechas, monedas, strings).
- Utilidades auxiliares (ej. helper para unir clases de Tailwind en `lib/utils.ts`).
