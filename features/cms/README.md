# Feature: CMS y Bloques Controlados (`features/cms`)

Este módulo encapsula la estructura del sistema de gestión de contenidos (CMS) interno, basado en bloques estructurados definidos en código.

## Responsabilidades Futuras
- Estructura y renderizado dinámico de bloques del sitio público.
- Esquema de bloques JSON (evitando constructores libres/plantillas desorganizadas).
- Formularios de administración para la edición de secciones.
