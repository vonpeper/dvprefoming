# Feature: SEO y Datos Estructurados (`features/seo`)

Este módulo proporciona componentes y utilidades auxiliares para inyectar Schema.org JSON-LD de forma dinámica en las páginas del sitio público.

## Responsabilidades Futuras
- Generador de datos estructurados para:
  - Eventos (`EventSchema` para obras y funciones).
  - Cursos o clases (`CourseSchema` para programas de la academia).
  - Academia local (`LocalBusinessSchema` para el negocio físico en León, Gto).
- Manejo dinámico de etiquetas meta complementarias y canonical links.
