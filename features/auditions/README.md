# Feature: Audiciones (`features/auditions`)

Este módulo encapsula las reglas de negocio, tipos de datos, interfaces y lógica de control para el registro y seguimiento de audiciones de la academia.

## Responsabilidades Futuras
- Lógica de creación de postulaciones a audición.
- Generación de folios transaccionales (sin contar registros directos).
- Integración con base de datos (PostgreSQL/Prisma) y validaciones de cupo.
