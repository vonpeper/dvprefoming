# Módulo de API (`app/api`)

Este directorio albergará las rutas de la API del servidor (API Routes) para interactuar con servicios externos y procesar webhooks.

## Responsabilidades Futuras
- Webhooks de Stripe (`/api/webhooks/stripe`).
- Webhooks de Evolution API o integraciones de mensajería (`/api/webhooks/evolution`).
- API de procesamiento y registro de audiciones.
- Integraciones con el motor editorial Manifiesto 21.
