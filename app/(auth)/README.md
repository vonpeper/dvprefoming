# Módulo de Autenticación (`app/(auth)`)

Este directorio albergará las rutas relacionadas con el sistema de autenticación de usuarios (alumnos, instructores y administradores) en el futuro.

## Responsabilidades Futuras
- Formularios de inicio de sesión (`/login`), registro (`/register`) y recuperación de contraseña.
- Integración con NextAuth.js.
