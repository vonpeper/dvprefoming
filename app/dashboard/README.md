# Módulo de Dashboard (`app/dashboard`)

Este directorio albergará las vistas administrativas y los paneles privados de alumnos y maestros.

## Responsabilidades Futuras
- Panel de control de alumnos (clases, inscripciones, historial de pagos).
- Panel de control de maestros (asistencia, calificaciones, horarios).
- Panel de control administrativo (audiciones, matrícula, control de CMS, configuraciones).
