# Módulo de Tipos TypeScript (`types`)

Este directorio contiene las definiciones de tipos e interfaces TypeScript globales de la aplicación.

## Responsabilidades
- Definición de tipos de entidades de negocio (`types/mock.ts`), estructurados para ser fácilmente migrables a esquemas de Prisma/PostgreSQL en el futuro.
- Interfaces del sistema de autenticación y de payloads para APIs de terceros.
